## 二、页面版式与配图识别规则（已实测确认）

原书每页版式由几类区域构成，**只有以下三类是配图，必须裁切**：

1. **标题页顶部大盘图**：每课首页（标题页）顶部有一张「上证指数」复合行情图（K线+成交量VOL+MACD+当日开高低收数据+缠师标注价格点），区域约为页面 x 130–870、y 135–405（千分比），是缠师当日解盘标注图，**每课第 1 张配图就是它**（个别课若该页无此图则不裁，以实际观察为准）。
2. **正文页实例 K 线图**：个股/指数实盘图（画面带「飞狐交易师」水印、右上/图中常有**缠师蓝色批注文字**，如"000778，20070827，高开后，没有突破前一天高位，一个典型是构成顶分型走势"）。一页可能上下排 2–3 张，**每张独立裁切**。
3. **正文内走势示意图**：缠师标注的结构图（分型/笔/线段/中枢/背驰/买卖点，常带 S1/X1、B0/A1/B2、a+A+b+B+c 等标注），嵌在文字段落之间或页中。

**必须排除的区域**：
- 购书广告块：白底黑字横条（内容为「《市场哲学的数学原理完全配图手册》铜版纸彩色印刷…购买网址 https://chanlun.taobao.com/ …QQ群 273237639」），位置不固定（多在页面右侧中上部，且**经常叠压在顶部大盘图或实例图上**）。裁切出的图若含广告块，**将该矩形区域填充纯白 RGB(255,255,255)**，不得保留任何广告文字。
- 页码（页脚数字）、页眉标题（"教你炒股票NN：xxx"）、首发日期行、正文文字区域。
- 前置篇（作者简介/前言/学习大纲/告散户书）与附录、后记**无配图**，不处理。

## 三、裁切技术要求

1. **渲染**：用 PyMuPDF（`import pymupdf` 或 `import fitz`）逐页渲染，`zoom=3.0`（矩阵 `fitz.Matrix(3.0,3.0)`）。若某张图裁出后标注文字仍不清晰，单独重渲染该页 zoom=4.0 再裁。
2. **定位与裁切**：渲染后 Read 整页图，凭视觉确定每张配图区域（用千分比坐标估算：像素 = 千分比 × 渲染宽/高 ÷ 1000）。用 PIL `Image.crop` 裁切。有边框的图按边框裁；无边框的按内容边缘留 10–20 像素白边。图注文字若位于图外紧邻下方且明显属于该图（如蓝色批注行紧贴图下方），可并入裁切；若属于正文文字则不并入。
3. **广告块涂白**：裁切图中若含广告白条，将其矩形区域用 PIL 填充纯白。判定标准：白色底 + 黑色文字、内容含"手册/铜版纸/购买网址/QQ群/作者主页"字样。涂白后应 Read 抽查确认无广告文字残留。
4. **文件规格**：PNG，RGB。命名 `chan-chNN-01.png` 起，**按图在书中的出现顺序全局编号**（顶部大盘图是第 1 张，其后按页面出现顺序递增）。一个图的编号一旦定下不可更改（md 已引用）。
5. **目录**：`source\images\chan\chan-chNN\`（目录不存在则创建）。

1. **插入位置**：按图在书中的出现顺序插入正文。图原本位于哪个文字段落之后，就插到该段在 md 中的对应位置之后（渲染页时可同时看到该页文字，用页面文字与 md 正文对照定位）；无法精确对应时，按全书出现顺序排在相关段落之后，宁后勿前。**不得改写、删除、移动任何既有正文文字**。
2. **插入格式**（图片行 + 空行 + 斜体图注行）：
   ```

   *图：上证指数2006-06-07当日K线图（缠师原注）*
   ```

   图注写法：`*图：{图类型与简要内容}（缠师原注）*`。图类型词：上证指数当日K线图 / {个股代码+名称}K线图（实例）/ 走势结构示意图 / 分型（顶/底）示意图 / 线段划分示意图 / 中枢示意图 / 背驰示意图 等；简要内容一句话（如"三张连续1分钟图"、"顶分型包含关系示例"）。
3. **绝对禁止**：
   - 修改 front matter（title/date/tags/categories/series/description/top_img）任何字段；
   - 修改 `<div class="summary-card">` 导读块、`<div class="post-nav">` 导航块及其内部链接；
   - 修改任何既有正文文字（包括错别字、术语、编者注）；
   - 把 HTML 属性引号 `class="summary-card"` 等 ASCII 双引号改动为中文引号（历史教训：引号替换会破坏样式）；
   - 在 md 中引入本地路径或非 `/images/...` 的图片路径。
4. 若一课页面确无任何配图（纯文字课），则不改该 md，并在交付报告中说明"无图"。
