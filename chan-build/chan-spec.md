## 1. 页面与页码换算

- PDF 页号 = 书内印刷页码 + 1（书内第 N 页 = PDF 第 N+1 页）。例如第一课书内页 12 = PDF 第 13 页。
- 每课内容范围 = 从该课起始 PDF 页到下一课起始 PDF 页之前（各课 PDF 页范围已写入参数表，直接照用）。
- 每课页面**右侧有购书广告块**（铜版纸彩色印刷、购买网址、作者主页、书友 QQ 群），页面上方常有上证指数 K 线图（含均线、成交量、MACD 等）——**这两类都不属于正文，一律剔除，不得写入 md**。

## 5. 渲染与转写流程（重要）

1. **渲染**：用 Python + PyMuPDF（已安装，`import pymupdf`）把本组 PDF 页渲染为 PNG，缩放 zoom=2.5 起步（约 1500×2100px，已实测清晰）；若某页小字读不清，对该页用 zoom=3.0 重渲染。参考代码：

   ```python
   import pymupdf
   doc = pymupdf.open(r"E:\生活\股票操练大全全套\超高清无水印《市场哲学的数学原理完全配图手册》2017(1).pdf")
   page = doc[pno]   # pno 为 0 起始页号（PDF 第 13 页 = pno 12）
   pix = page.get_pixmap(matrix=pymupdf.Matrix(2.5, 2.5))
   pix.save(r"E:\生活\股票操练大全全套\chan-build\work-<组名>\page013.png")
   ```

2. **分批**：一次渲染 5-10 页，全部转写完成后再渲染下一批，避免内存与上下文压力过大。
3. **逐页转写**：用 Read 工具打开 PNG，结合图片附带的 OCR 表格与肉眼核对，逐字转写正文。**OCR 表格可能有错，以肉眼所见为准。**
4. **剔除**：右侧购书广告块（"《市场哲学的数学原理完全配图手册》铜版纸彩色印刷…购买网址 https://chanlun.taobao.com/ 作者主页 blog.sina.com.cn/gqoqqq 书友QQ群273237639"）与页面上方 K 线图一律不写入 md；正文中对图的引述文字（如"如下图"）保留，图本身不插入。
5. **忠实原文**：错别字、特殊术语（"背弛"、"本ID"、"缠中说禅"等）照原样保留，不改写、不润色、不补字；标点尽量照原样；段落按扫描页自然分段。
6. 每课依次写：front matter → summary-card → 首发小注 → 正文 → 底部导航。
